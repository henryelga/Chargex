# ⚡ Chargex

Chargex is a modern iOS application built with SwiftUI that helps electric vehicle users easily locate, manage, and track charging stations across Ireland. Designed with sustainability in mind, Chargex empowers users to make environmentally conscious decisions while providing useful insights into their charging habits.

# 🌍 Purpose

Chargex contributes to a more sustainable future by promoting the use of electric vehicles and helping users reduce their carbon footprint. By tracking usage and estimating CO₂ savings, the app aligns with global sustainability goals and encourages greener transportation choices.

## 🧠 Technical Highlights
- Built using SwiftUI with a focus on modern iOS design principles
- Follows structured development practices inspired by MVC architecture
- Implements Core Location for real-time user positioning
- Uses Apple Maps integration for navigation
- Incorporates local notifications to enhance user engagement
- Supports gesture-based interactions (e.g., swipe to delete)
- Includes local data storage for saved stations and user preferences
- Designed with accessibility and UX best practices in mind

## 🔒 Permissions

Chargex requests the following permissions:

- Location Services – to display nearby charging stations
- Notifications – to send charging reminders

## 🌱 Sustainability Impact

Chargex is designed to support the [United Nations Sustainable Development Goal 13](https://sdgs.un.org/goals/goal13), which focuses on combating climate change and reducing environmental impact.

By promoting the use of electric vehicles and providing insights into estimated CO₂ savings, Chargex helps users make more sustainable transportation decisions.

The app contributes to environmentally friendly mobility by:

- Supporting EV adoption
- Allowing users to track their environmental impact
- Encouraging efficient and mindful charging behaviour
